# 확인 결과

## 최신 점검: 2026-09-23 공개 준비

- Edge(Chromium) 브라우저의 320·390·768·1440px, 3개 페이지에서 가로 넘침·메뉴 열기/닫기·포커스 복원·페이지별 동작 점검 통과. 모바일 화면은 터치 입력을 모사했습니다.
- 6단계 제작 안내, 20개 기능 펼침, 문의 3개 선택, 선택 작품명·이메일 연계, 확정 가격 50만원·150만원과 부가세 별도 표시 통과.
- 7개 데모 팝업의 주소·새 탭 링크·종료 시 iframe 제거·키보드 포커스 복귀 통과. 이 동작 점검에서는 외부 iframe 내용을 대체했고, 별도로 실제 7개 주소에 GET 요청하여 모두 200 응답과 삽입 차단 헤더 없음을 확인했습니다.
- JavaScript 비활성 환경에서도 카카오톡·이메일·전화 기본 링크 정상. 메시지 전송·이메일 발송·통화는 실행하지 않았습니다.
- 세 HTML의 대표 주소·공유 정보·검색 차단 유지, 사이트맵 XML 파싱·3개 URL, robots.txt·XML·공유 이미지의 HTTP 응답 형식 확인.
- 새 공유 이미지 1200 × 630px, 기존 폰트 로드 및 육안 확인. PC·모바일 가격 영역의 부가세 표기 육안 확인.
- app.js·content.js·server.mjs 문법 및 변경분 공백 검사 통과. 브라우저 실행 오류·로컬 리소스 오류 없음.

## 남은 자료와 제한

- 실제 포트폴리오 영상은 미수령. 현재 정지 화면 표시. 실제 영상 연결 후 해당 파일의 화질·길이·반복 재생은 다시 확인합니다.
- 나머지 6개 데모 주소 미수령. 실제 주소를 받으면 각각 등록하고 삽입 가능 여부를 점검합니다.
- 카카오톡 채널 주소 미수령.
- 실제 전화 연결이나 이메일 발송은 실행하지 않았습니다. 링크 생성만 확인했습니다.

- 실제 iPhone/Safari 기기 테스트와 공개 도메인 테스트는 진행하지 않았습니다.
