## 사용자가 확인할 내용

1. 첫 화면에서 캐릭터가 페이지를 완성하는 장면과 ‘디자인으로. → 당신답게. → 움직임을. → 자연스럽게. → 섬세하게. → 원하는 대로. → 웹사이트로.’ 문구 전환을 확인합니다. 히어로는 자동 재생되며 메뉴를 열거나 화면을 벗어나면 멈춥니다. 기기의 동작 줄이기 설정에서는 정지 화면을 표시합니다.
2. 포트폴리오 7개의 이미지·설명 영역을 누르면 실제 데모가 열립니다. Ctrl+클릭은 새 탭으로 열립니다.
3. 데모 상단의 ‘이 작품으로 문의’를 누르면 프로젝트 문의 페이지로 이동하며 관심 작품명이 표시됩니다. 새로고침해도 선택이 유지됩니다.
4. 이메일·전화 버튼의 연결 정보를 확인합니다. 메일 발송과 통화는 직접 실행해야 합니다.
5. 문구, 가격, 로고와 모션에서 바꾸고 싶은 부분을 알려주세요. 코드를 직접 수정하지 않으셔도 됩니다.

미리보기 주소:

- 제작 안내: http://127.0.0.1:4186/services.html

## 2026-09-18 변경

Hello Monday를 다시 확인한 뒤 사용자와 흑백 캐릭터 방향을 선택했습니다. 흰 배경, 중앙 애니메이션과 아래의 큰 제목으로 재구성했습니다. 참고 사이트의 영상·캐릭터 파일은 사용하지 않았으며, 원본 SVG 일러스트와 GSAP로 구현했습니다. 화면 밖에서는 반복 재생을 멈춥니다.

Cafe24Moyamoya는 사용자 다운로드 폴더의 원본 WOFF2를 사용합니다. 로고·주요 제목·가격에 적용했고, 긴 설명·버튼·연락처는 Pretendard를 유지했습니다. 기존 자체 제작 SVG 로고 파일은 보존되어 있지만 현재 상단 로고에는 사용하지 않습니다. 하단 영역은 v0.4에서 제거했습니다.

주요 수정 파일: dist/index.html, dist/styles.css, dist/app.js. 추가 파일: dist/assets/Cafe24Moyamoya-Regular-v1.0.woff2 및 License-Moyamoya.pdf.

제작안내를 과정 애니메이션→상세 가격→추가 기능 순서로 변경했습니다. 6개 장면이 한 번 순서대로 재생된 뒤 마지막 장면에 머뭅니다. 단계 이름을 클릭하면 해당 설명을 멈춰 읽을 수 있습니다. 화면 밖·메뉴 열림·탭 숨김에서 정지하고, 동작 줄이기 설정에서는 단계 직접 선택을 지원합니다.

가격은 기존 가안 50만원부터 / 150만원부터를 유지하면서 기본 제작 범위와 추가 견적 예시를 각각 설명했습니다. 레퍼런스 둘러보기와 맞춤 제작 상담하기 링크를 제거했습니다. 원래의 전액 결제 조건을 유지하며 새로운 납기나 수정 횟수는 제시하지 않았습니다.

수정 파일은 dist/services.html, dist/styles.css, dist/app.js입니다. 기존 미리보기를 새로고침하면 확인할 수 있습니다. v0.8 ZIP은 이전 버전 보관본이고, 최신 작업 파일은 dist에 있습니다. Git 저장소·브랜치 및 커밋·푸시·PR·병합·배포는 없습니다.

## v0.12 변경

가격 설명을 처음 홈페이지를 만드는 고객이 순서대로 읽는 구성으로 바꿨습니다. 본문을 PC 18px·모바일 17px로 키우고 진하게 표시하며, 작업 항목마다 제목과 짧은 설명을 묶었습니다. 기본 작업과 추가 작업의 예시, 한 페이지와 별도 페이지의 그림 비교를 제공합니다. 상단 제작 애니메이션과 기존 가격은 그대로입니다. 이번 화면 수정 파일은 dist/services.html과 dist/styles.css입니다.
## v0.13 변경

50만원·150만원 상품을 같은 단일 열 구성으로 정리했습니다. 상품명 다음 줄에 가격을 두고, 소개→기본 포함 작업→추가 비용 순서로 읽습니다. 본문은 PC 18px·모바일 17px, 보통 굵기로 통일하고 작은 제목만 20px·600 굵기로 구분합니다. 중복되는 항목 제목, 불릿 들여쓰기, 예시의 좌우 배치를 없애고 왼쪽 시작선과 문단 간격을 맞췄습니다. 상품명과 가격에는 기존 Cafe24Moyamoya를 사용합니다.

화면 수정 파일은 dist/services.html과 dist/styles.css입니다. 현재 로컬 미리보기를 새로고침하면 반영됩니다. 가격과 상단 제작 과정은 그대로 유지했습니다. Git 저장소·브랜치 및 커밋·푸시·PR·병합·배포 없음.
## v0.14 변경

두 상품의 시작가격을 본문에서 분리했습니다. PC에서는 설명 오른쪽의 연한 배경 영역에 표시하고, 해당 상품을 읽는 동안 스크롤 위치에 맞춰 유지합니다. 1000px 이하에서는 상품명 아래, 설명 위에 가격 영역이 놓입니다. 본문 문구·글자 크기·간격, 시작가격 50만원·150만원은 유지했습니다. 화면 변경은 dist/services.html과 dist/styles.css에 반영했습니다.
