# FLOWAX-PAGE PRD

작성일: 2026-09-17  
버전: 0.1 — 인터뷰 승인안 및 1차 구현 기록  
상태: 사용자 승인 후 1차 로컬 구현 완료. 실제 작품 1개 연결. 영상·나머지 작품·카카오톡 주소 수령 대기. 공개 배포·Git 푸시 없음.

## 1. 문서 기준

- **확정:** 사용자 인터뷰에서 선택한 요구사항.
- **임시 가격:** 사용자가 추후 숫자만 바꿀 수 있도록 요청한 가안.
- **제안:** 구현을 구체화하기 위한 기본값. 아직 사용자가 개별 선택한 값은 아님.
- **준비 필요:** 실제 데모 주소, 연락처, 영상 등 추후 받을 자료.

PRD 확인 후 제작한다. 추가 구성은 임의로 늘리지 않는다. 자료 요청이나 추가 인터뷰는 한 번에 한 질문씩 진행한다.

## 2. 목표와 고객 — 확정

홈페이지 제작 서비스의 디자인·모션 역량을 보여주고, 방문자가 포트폴리오를 직접 체험한 뒤 상담을 시작하게 한다.

**히어로에서 관심 형성 → 포트폴리오 미리보기 → 실제 데모 체험 → 상담**

- 특정 업종으로 고객을 제한하지 않는다.
- 가장 중요한 강점은 뛰어난 디자인과 모션이다.
- 합리적인 가격과 빠른 제작, 자유로운 맞춤 제작, 편안한 상담도 전달한다.
- 레퍼런스 기반 제작과 완전 맞춤 제작을 함께 제공한다.
- 임의의 납기 보장, 실적·고객 수·후기 등 근거 없는 정보를 쓰지 않는다.

내비게이션은 같은 페이지의 해당 영역으로 이동하는 방식을 기본 제안으로 한다. 최종 메뉴명과 배열은 디자인 단계에서 정한다.

### 제외 사항

- FLOWAX-PAGE 자체의 회원가입·로그인·온라인 결제
- 홈페이지 내부 문의 양식
- 포트폴리오 등록용 관리자 화면
- 별도 전체 포트폴리오 페이지
- 포트폴리오 업종·스타일 필터 및 검색
- 별도 제작 철학·소개 확장 섹션·FAQ
- 고정된 제작 기간과 수정 횟수 안내
- 유지보수·월 정액·납품 후 수정에 관한 안내
- 미제공 고객사 명단·후기·실적 수치
- 추가 요청 없이 도입하는 광고·방문 추적 도구

회원·결제·관리자 기능은 고객 의뢰로 제작할 서비스의 예시에 포함된다. FLOWAX-PAGE 자체 구현 기능과 구분한다.

### 로고

기존 로고와 색상 자료는 없으며 새로 설계한다.

- FLOWAX-PAGE의 **글자 자체를 디자인한 커스텀 로고**.
- 독창적이고 현대적인 인상.
- 글자 형태·연결·여백에 일관된 시각적 규칙 적용.
- 흑백, 작은 헤더 크기, 정지 상태에서도 식별 가능.
- 히어로에서는 글자의 분리·연결·변형을 모션으로 확장 가능.
- 사용자 선택과 다른 독립 심볼·축약 문자 중심 구조로 임의 변경하지 않음.
- 사용 글꼴·자산의 사용 및 수정 조건 확인. 유료 구매는 사전 안내.

### 레퍼런스

핵심 레퍼런스: [Hello Monday](https://www.hellomonday.com/)

사용자는 이 사이트 같은 느낌과 애니메이션을 원한다. 인터뷰에서 선택한 해석은 **사이트 자체가 커서·스크롤에 반응하는 경험 + 홈페이지가 만들어지는 연출**이다.

확인 한계: 페이지 텍스트는 확인했으나, 당시 브라우저 도구 오류로 실제 애니메이션 동작을 시각적으로 검증하지 못했다. 아래 사양은 사용자와 합의한 방향이며, 레퍼런스의 특정 효과를 확인하거나 그대로 재현한 사양은 아니다. 구현 전 화면과 움직임을 다시 확인한다.

디자인 검토 기준:

- 작품과 구체적인 서비스 내용이 중심인가?
- 로고와 히어로가 일반적인 글자 배치·등장 효과에 머물지 않는가?
- 같은 카드 형태와 등장 모션을 모든 섹션에 반복하지 않는가?
- 효과 때문에 작품·가격·문의 방법을 파악하기 어렵지 않은가?
- 추상적인 홍보 문구보다 실제 제공 내용을 설명하는가?

## 5. 히어로

### 확정 연출

1. 접속 시 짧고 강렬한 자동 등장.
2. 글자·사진·버튼 등 구성 요소가 모여 홈페이지가 만들어짐.
3. 이후 스크롤에 따라 홈페이지가 완성되는 장면 전개.
4. PC에서는 커서 반응을 결합.
5. 밝은 포트폴리오 영역으로 연결.

### 구현 제안

- 자동 도입부는 약 **2~3초**를 초기 검토값으로 사용하고 시안에서 조정.
- 연출 종료를 기다려야 하는 강제 대기 화면을 두지 않음.
- 방문자는 언제든 스크롤하거나 메뉴로 이동 가능.
- 모바일은 커서 효과를 제외하고 자동 등장·스크롤 중심으로 재구성.
- 소리 자동 재생 금지.
- 움직임 줄이기 설정에서는 내용을 읽을 수 있는 간결한 전환으로 대체.
- 효과의 개수보다 하나의 명확한 연출 흐름을 우선.

## 6. 포트폴리오

### 자료와 성장 계획 — 확정

- 현재 접속 가능한 자체 제작 데모 **7개** 보유.
- 첫 공개 목표 **10개**, 이후 약 **30개**까지 확장 계획.
- 이는 사용자 보유·확장 계획이다. 이번 작업에서 미보유 데모를 임의로 제작하지 않는다.
- 향후 고객 작업도 로고와 세부 데이터를 바꾼 공개용 포트폴리오 버전으로 게시.
- 공개용 데모를 실제 고객사 명단이나 원본 납품 실적으로 오해하게 표현하지 않음.

### 목록 — 확정

- 메인페이지 안에 배치.
- PC는 홈페이지 화면이 크게 보이는 **정돈된 2열**.
- 일부 작품을 먼저 보여주고 **더 보기**로 같은 페이지에 추가.
- 추가 후에도 보던 위치 유지.
- 업종·스타일 필터, 검색, 별도 목록 페이지 없음.

초기 제안값:

| 항목 | 제안 |
|---|---|
| 최초 표시 | 6개 |
| 더 보기 | 최대 6개씩 추가 |
| 모바일 | 1열 |
| 목록 끝 | 남은 작품만 표시하고 더 보기 종료 |
| 기본 정보 | 작품명, 정지 이미지·영상, 데모 주소, 필요한 경우 작품별 시작가격 |

준비되지 않은 작품을 가짜 결과물로 채우지 않는다. 공개 목표 수량보다 적다면 실제 준비 수량과 공개 시점을 확인한다.

### 미리보기 — 확정

- PC: 작품에 커서를 올리면 짧은 영상 재생.
- 모바일: 화면 중심에서 보고 있는 작품 하나만 무음으로 자동 재생.
- 영상 구성: **핵심 모션 → 주요 구간의 빠른 스크롤**.
- 클릭·터치하면 실제 데모 팝업 열기.

동작·품질 제안:

- 영상 길이 약 **6~8초**를 첫 검토값으로 사용.
- 동시 재생은 하나로 제한.
- 커서가 떠나거나 모바일 화면 밖으로 나가면 재생 중단.
- 키보드로 작품을 선택하고 데모를 열 수 있도록 제공.
- 영상 미준비·재생 차단 시 정지 이미지 표시. 데모 열기는 유지.
- 움직임 줄이기 설정에서는 자동 재생을 줄이거나 정지 이미지로 대체.
- 실제 영상 비율·화질·용량은 대표 작품으로 확인한 뒤 확정.

### 영상 준비 — 확정

사용자가 필요할 때 작품별로 직접 녹화해 전달한다. 자동 녹화 시스템은 이번 범위에 포함하지 않는다.

필요한 시점에 한 작품씩 녹화 구간, 화면 크기, 대기 시간, 스크롤 순서, 길이, 전달 방법을 안내한다. 대표 작품 하나의 규격을 맞춘 뒤 순차적으로 준비한다.

## 7. 데모 팝업

### 확정

- PC: 현재 페이지 위에 크게 열리는 팝업.
- 모바일: 화면을 가득 채우는 팝업.
- **새 탭에서 보기**를 보조 수단으로 제공.
- 닫으면 원래 작품과 목록 위치로 복귀.

### 조작 구성 — 제안

상단에 **작품명 / 새 탭에서 보기 / 문의 / 닫기**를 간결하게 배치한다.

- 작품명과 닫기는 항상 확인 가능.
- 문의는 기존 문의 영역으로 연결. 별도 접수 양식 없음.
- 카카오톡에 작품명이 자동 전달된다고 보장하지 않음. 실제 연결 방식 확인 후 가능한 범위 결정.
- 바깥 페이지 스크롤 고정, 배경 영상·무거운 연출 일시정지.
- 선택한 데모 하나만 불러오고 닫을 때 실행 종료.
- 키보드 접근과 닫기를 확인하고, 닫은 뒤 선택 작품으로 초점 복원.

### 호환성 확인

내부에 다른 사이트를 표시하는 iframe 방식을 우선 검토한다. 데모별 외부 표시 제한을 실제 주소 수령 후 확인한다.

- 최초 화면뿐 아니라 내부 메뉴, 스크롤, 영상, 주요 상호작용 점검.
- 표시 제한을 FLOWAX-PAGE 쪽 코드만으로 해결할 수 있다고 가정하지 않음.
- 데모의 게시·보안 설정 변경이 필요하면 대상과 영향을 설명한 뒤 진행.
- 표시 불가 시에도 새 탭으로 직접 열 수 있게 구성.
- iframe의 로드 이벤트만으로 실제 표시 성공을 단정하지 않음.
- 기존 데모 코드나 운영 설정은 임의 변경하지 않음.

## 8. 제작 서비스·가격

### 서비스 범위 — 확정

| 구분 | 레퍼런스 기반 제작 | 완전 맞춤 제작 |
|---|---|---|
| 출발점 | 준비된 데모 선택 | 고객 요구에 맞춰 설계 |
| 기본 페이지 범위 | 선택한 데모의 전체 페이지 | 원페이지 |
| 기본 조정 | 로고·사진·문구·색상·글꼴·간격 조정, 기존 섹션 순서 변경·삭제 | 구체적인 기본 구성은 상담에서 확정 |
| 추가 작업 | 새 섹션·레이아웃·효과·기능 제작 | 추가 페이지·기능 등 합의 범위를 넘는 작업 |
| 가격 운영 | 작품별 분량·난이도에 따른 시작가격 | 기본 시작가격 + 추가 작업 견적 |

레퍼런스 기반 제작은 선택한 데모의 기존 구성과 애니메이션을 바탕으로 한다.

### 임시 가격

| 항목 | 임시 값 |
|---|---:|
| 레퍼런스 기반 최소 시작가격 | 500,000원 |
| 완전 맞춤 시작가격 | 1,500,000원 |

- 화면 표기 초안: **50만원부터 / 150만원부터**.
- 사용자 요청으로 설정한 기획·시안용 가안이며 확정 판매가가 아님.
- 개별 작품 가격은 실제 작품 확인 후 임시 값을 배정하거나 사용자 값을 받음.
- 숫자를 한곳에서 수정하면 관련 화면 전체에 반영되도록 구성.
- 추가 옵션은 **항목만 공개**, 금액은 상담 후 안내.
- 옵션 가격표와 예상 금액 계산기는 제작하지 않음.
- 부가세 포함 여부와 외부 서비스 이용료 표기는 실제 공개 전에 확인.

## 9. 추가 가능한 기능

고객이 의뢰할 수 있는 기능을 폭넓게 소개한다. **분야명을 누르면 세부 기능이 펼쳐지는 목록**으로 구성한다.

고객용 문구에서는 ‘바이브코딩’이라는 개발 방식보다 필요한 기능을 구체적으로 안내한다. 모든 기능을 무조건 제공하거나 기본 제작비에 포함한다고 보장하지 않는다.

안내 문구 제안:

> 필요한 기능을 함께 설계합니다. 아래 기능은 제작 예시이며, 구체적인 범위와 연동 가능 여부는 상담 후 안내합니다.

| 분야 | 세부 기능 예시 |
|---|---|
