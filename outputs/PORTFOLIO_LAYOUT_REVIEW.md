# FLOWAX-PAGE 포트폴리오 UI·UX 검토
2026-09-18 · 실제 데모 7개 적용본 v0.8

## 이번 배치의 판단
포트폴리오 배경은 흰색이 적합합니다. 작품마다 색과 분위기가 강하므로 주변 배경의 개입을 줄여 이미지에 시선을 모았습니다. 흰 히어로에서 작품 목록으로도 자연스럽게 이어집니다. 서비스·문의 페이지는 이번 수정 범위 밖이며 기존 디자인을 유지했습니다.

PC에서는 두 작품씩 비교할 수 있는 기본 구조에 펜션 한 작품을 넓게 배치했습니다. 계속 같은 크기로 반복되는 목록에 변화를 주면서, 건축물과 수평선이 있는 사진의 장점도 살립니다. 작품 순서는 사용자가 전달한 순서입니다.

| 순서 | 작품 | PC 배치와 의도 |
| --- | --- | --- |
| 01–02 | 피부과 · 시계 | 2열. 밝고 부드러운 피부과와 어두운 제품 화면을 대비시킵니다. |
| 03 | 제주 펜션 | 가로 전체. 공간과 풍경을 넓게 보여주며 목록의 호흡을 바꿉니다. |
| 04–05 | 연구소 · 여행사 | 2열. 우주 탐사의 어두운 화면과 여행의 따뜻한 색감을 비교합니다. |
| 06–07 | 타투 · 렌트카 | 2열. 섬세한 그림과 역동적인 주행 화면으로 마무리합니다. |

모바일에서는 같은 순서의 1열입니다. 우측 메뉴와 내용이 겹치지 않게 여백을 확보했고, 작은 화면에서도 이미지·업종·이름·설명의 순서를 유지했습니다.

## 문구와 정보의 배치

- 섹션 제목: **“마음에 드는 화면을 직접 경험해보세요.”** 포트폴리오에서 할 수 있는 행동을 바로 설명합니다.
- 보조 설명: “서로 다른 업종의 디자인과 움직임을 살펴보세요. 작품을 선택하면 데모를 직접 체험할 수 있습니다.”
- 이미지 아래 첫 줄: 왼쪽에는 작품 번호와 업종, 오른쪽에는 **데모 보기 ↗**를 둡니다. 마우스를 올리지 않아도 클릭할 수 있음을 알 수 있습니다.
- 다음 줄: 작품명을 Cafe24Moyamoya로 표시합니다. 설명은 읽기 쉬운 Pretendard를 유지합니다.
- 마지막 줄: 화면의 특징을 한 문장으로 설명합니다. 확인되지 않은 매출·성과·실제 고객 실적은 표시하지 않았습니다.
- 반복되던 카드별 “포트폴리오 데모” 표시는 줄였습니다. 팝업 상단의 데모 안내는 유지합니다.

썸네일은 모두 실제 제공된 사이트 화면입니다. 시계는 브랜드 업종을 즉시 알아볼 수 있도록 제품 컬렉션 화면을, 타투는 디자인 아카이브를 선택했습니다. 다른 작품도 로딩 화면 대신 대표 장면을 사용했습니다.

## 사용 흐름

1. 7개 작품을 한 번에 살펴봅니다. 마지막 렌트카가 더 보기 뒤에 숨지 않습니다.
2. 이미지나 설명 영역을 클릭하면 해당 사이트의 데모 팝업이 열립니다.
3. 팝업에서 직접 체험하거나 ‘새 탭에서 보기’를 선택합니다.
4. ‘이 작품으로 문의’를 누르면 선택한 작품명이 문의 페이지와 이메일 제목에 전달됩니다.

키보드 Enter로 작품을 열 수 있으며, 팝업 상단에 포커스가 있을 때 Esc로 닫고 원래 작품으로 돌아갑니다. Ctrl+클릭은 브라우저의 새 탭 동작을 유지합니다.

작품별 제목 구조, 키보드 조작, 이미지 크기 지정·지연 로딩을 점검했습니다. 이는 [Vercel Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)의 관련 항목을 참고한 부분 점검이며 전체 접근성 인증을 의미하지 않습니다.

## 확장과 이미지 처리

- 실제 7개를 기본 노출하고, 추가 작품은 6개씩 더 표시합니다. 30개 데이터로 확장 동작을 확인했습니다.
- 작품 정보는 content.js에서 관리합니다. 새 작품은 기존 카드 형식을 그대로 사용하고, 필요할 때만 대표 작품을 넓게 배치할 수 있습니다.
- WebP 이미지와 작은 화면용 파일을 분리했습니다. 보이지 않는 이미지는 가까이 스크롤했을 때 불러옵니다.
- 화면마다 실제 데모 7개를 동시에 실행하지 않습니다. 선택한 작품의 팝업만 연결합니다.
- 지금은 정지 썸네일입니다. 마우스를 올렸을 때 재생할 짧은 영상은 사용자 녹화 파일을 받은 뒤 순서대로 연결합니다.

## 확인 결과와 남은 사항

- 화면 너비 320·390·768·1440·1920px에서 가로 넘침·카드 문구 잘림 없음.
- 7개 썸네일 정상 표시, 펜션 전체 너비 배치 및 모바일 1열 확인.
- 외부 데모 7개 모두 팝업 내 본문 표시 및 작품별 문의 이동 확인.
- 7개 문의 페이지의 작품명과 이메일 제목 일치.
- 키보드 열기·닫기·초점 복귀, Ctrl+새 탭, 7→13→19→25→30개 확장 정상.
- JavaScript 문법 검사 통과. 로컬 페이지 실행 오류 없음.
- 실제 iPhone/Safari는 이번 점검 대상이 아닙니다. 모바일 화면은 Edge에서 크기를 바꾸어 확인했습니다.
- 외부 데모 내부에 포커스가 있으면 Esc가 부모 팝업에 전달되지 않을 수 있습니다. 상단 × 버튼을 사용할 수 있습니다.
- 아직 필요한 자료: 미리보기 녹화 영상, 카카오톡 채널 주소. 가격과 공개 주소는 추후 확정합니다.
- 로컬 미리보기 반영 완료. Git 저장소·브랜치 없음. 커밋·푸시·PR·병합·공개 배포는 하지 않았습니다.
